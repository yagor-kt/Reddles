# Загадки

Офлайн-викторина на русском языке: выбирайте уровень сложности, отгадывайте загадки и следите за своим результатом.

## Возможности

- Вход по имени и паролю с автоматическим созданием аккаунта.
- Три уровня сложности: лёгкий, средний и сложный.
- Перемешивание загадок и вариантов ответов.
- 15 секунд на ответ и три ошибки на партию.
- Подсветка правильного и неправильного ответа.
- Сохранение рекорда и статистики на устройстве.

## Технологии

- Kotlin
- Jetpack Compose и Material 3
- Navigation Compose
- Room с KSP
- Корутины и StateFlow
- Архитектура MVVM

Приложение работает без сети.

## Запуск

Откройте проект в Android Studio и запустите конфигурацию `app` на устройстве или эмуляторе.

- Пакет: `com.example.riddles`
- Минимальная версия Android: API 26
- Compile SDK: 35

## Демо-аккаунт

- Имя: `Игрок`
- Пароль: `1234`

Можно также ввести новое имя и пароль — аккаунт создастся автоматически.

## Данные

Пользователи, статистика и загадки хранятся локально в базе Room на устройстве.
